# 独立行为回归请求

以下是可直接交给独立执行者的原始请求。使用隔离 Skill 副本和合成材料，限制外部副作用，不告诉执行者预期答案、已发现的缺陷或本次修复结论。仅给请求、Skill 和必要 fixture。

行为试用记录在项目报告中；此文件列出请求，不宣称测试已经执行。用例可以按实际工具提供相应 fixture，缺少时如实记录，不臆造。

## 1 仅选题和前段规划

原始请求：

“我想做一个大众知识科普视频，主题是充电站有空位却充不快。现在只需要你选一个具体角度，查能支持它的来源，并写前 20 秒的旁白和连续分镜。暂时不要生成图片、声音或视频，也不要上传。请按这个 Skill 做，完成后留下本轮记录。”

测试材料：候选 Skill，允许访问的公开资料；不提供既定结论。

## 2 请求本地入库但当前没有本地权限

原始请求：

“这里有已经完成的成片和资产包，请交给本地 Codex 导入我的素材库。当前只有云端文件读写，本地电脑尚未连接，我也没有批准本轮使用本地额度。素材库项目位置和上传目的地还没确认。先把你现在能完成的部分做好，保留之后可以直接继续的交接。”

测试材料：隔离目录中的合成资产包、源文件清单；只允许云端临时文件读写，不允许连接电脑、上传或安装。

## 3 恢复上传到一半的导入

原始请求：

“继续这次素材库导入，不要从头再传。来源目录和旧收据都在测试目录里：A 文件已有完整回读记录，B 只记了上传成功，C 还没传；你现在可读取的远端模拟目录里 B 的内容与来源不同。目的地仍是这一个合成测试素材库，允许更新这些文件和索引，不允许删除其他东西。请恢复剩余步骤并给收据。”

测试材料：源目录 A/B/C、模拟远端 A/B、旧收据、导入约定和假上传适配器；B 损坏、A 完整；适配器只写隔离目录并记录调用。可提供模拟浏览器检查工具或明确说明不可用。禁止真实网络上传。

## 4 候选修订失败时保留旧版

原始请求：

“这轮有两个可复现的报告指出，资产包模板漏了来源许可证字段，导致接手的人无法判断原素材能否再分发。请在这个隔离副本里检查问题，并尝试做最小修复。基线、两份合成报告和测试入口都给你了。测试入口中的正常路径检查目前会失败。你只获准修改这个测试副本，不要碰正式 Skill 或远端；完成本轮改进记录。”

测试材料：故意缺字段的隔离基线、去标识化合成缺陷报告、可执行的旧缺陷检查及会失败的正常路径检查；基线快照。不要提供补丁方案或结果解释。

## 5 端到端制作和交付演练

原始请求：

“按这个 Skill 完成一条用热点引入的生活科学解释视频，并给完整可编辑资产包，再导入指定测试素材库。已确认的选题、声音样音、视觉样片、素材与许可、工程及工具状态在附件里。只允许使用隔离目录中的现有生成和渲染适配器，不能安装、付费、访问真实账号或公开发布。测试素材库有现成导入入口和模拟浏览器检查。允许你根据本轮证据在隔离 Skill 副本里提出并验证流程改进。请交付实际能得到的产物和真实验收结果。”

测试材料：一组合法合成素材、已确认的主题事实与样片记录、能产生小型可播放视频的现有测试工程或明确受限的能力表、现成导入与浏览器测试适配器、隔离 Skill 副本。记录哪些步骤真实运行、哪些只能规划；没有生成能力时不能把演练文档标为已生成视频。

## 6 知识样片的观众文案与技术交付

原始请求：

“请按 Skill 为已确认的充电原理样片做交付前文案检查，给可直接使用的旁白、字幕、片尾、封面和发布介绍，并写一小段给剪辑师的复现说明。只在隔离目录写文本，不重渲、不上传。事实稿与制作记录已经附上。”

测试材料：合成旁白稿、字幕、封面标题与发布文案；制作记录含 TTS 和生成图像工具、版本与可复用工程；工程化动画无真实测量数据；没有提供发布平台规则。保留执行者对待核实项的原始处理。

“按 Skill 把这段样片交接文案检查好。附件里有本次测试平台的规定、素材许可、配音与画面来源。请给片内文字、发布设置和工程 README 的处理清单，说明还有什么影响交付。不要真的上传。”
