## README 内容模板

README 面向创作者复用，保留真实且必要的工具、依赖、声音来源和方法信息。面向观众的作品介绍不主动加入这些制作说明；必要标识、事实边界和署名依[相关规则](../references/quality-and-delivery.md#观众文案与必要披露)核验。

- 作品题目、版本、尺寸、帧率、时长和文件用途
- 如何直接看成片；哪些文件用于进一步编辑
- 工程运行环境、依赖、入口和复现步骤，指向相对路径
- 字体是否包含全部字符；修改文案后缺字如何处理
- 音频参考、保留的原声和任何处理方式
- 事实及示意边界、来源、许可和改编说明
- 已完成的检查、未覆盖部分和最后验证日期
- 发布状态与交付范围，不写成未经授权的“已公开发布”

相对路径、用途、格式、大小字节、SHA-256、版本、是否可再分发、上传状态、下载回读状态、验证时间。
