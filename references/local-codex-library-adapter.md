# 本地 Codex 素材库入库 adapter

用于把已经完成或可恢复的资产包交给本地 Codex，导入用户指定的素材库项目。它是能力和交接约定，不绑定任何宿主工具、账号、域名、上传接口或公开权限。

## 前检与执行器选择

1. 确认本轮是入库操作：哪些文件、哪个素材库、何种可见范围、允许哪些改动。整理当前用户对本地使用和额度的限制；仅允许最终入库时，不把渲染、生成、研究搬到本地。
2. 通过宿主提供的连接或环境发现能力检查真实连接状态。不能因为主对话没有鼠标或终端工具，就断定本地完全不可用；也不能把“已配对”当“当前在线”。
3. 查找已存在且确实对应这个项目和入库任务的本地 Codex 会话，能安全继续时优先续用。明确核验会话与项目对应关系，不能给无关会话发任务。没有合适会话才通过宿主支持的方式新建；不要猜会话 ID 或直接绕到未授权的本地通道。
4. 本地项目位置优先来自本次指示、已确认项目记录或本地执行器可核验的工作区。先做最小范围定位；不要全盘搜索私人文件。若有多个合理目标，问一个定位问题。
5. 工具或连接不足时，输出完整 [交接文件](../templates/local-library-handoff.json)，把需要的最小动作和阻断点告诉用户。不得声称已在本地下载、上传、改索引或播放；连接和访问未授权前不替代执行。

## 本地执行前必须阅读

本地执行器先读取项目约定、AGENTS.md（若存在）、现有导入脚本、README、配置示例、索引结构及相关测试，检查工作区状态。说明准备复用的脚本和影响文件；遵守项目已有命名、存储和发布流程。

保护用户尚未提交的修改。禁止为了“干净工作区”重置、强制覆盖、切分支丢改动或自动清理。若索引的并行修改发生冲突，保留双方内容，重新读取并合并授权范围；不盲目重试旧版本覆盖。

只能调用已发现且适用于本项目的上传方式。不要根据网盘域名或网页结构臆造上传 API，不将过去项目的接口复制成默认接口。需要新软件、凭据、权限或费用时，暂停对应步骤请求必要授权。

## 跨执行器取文件

- 云端路径不是本地路径。本地执行器必须通过已授权、实际可用的文件传输机制获得字节；交接写明传输方式、文件标识或可访问来源，避免只给云端绝对路径
- 从源资产目录生成相对路径、字节数和 SHA-256 清单。可使用 `scripts/asset_manifest.py`，具体用法见 [工具说明](tooling.md)
- 本地下载或接收完成后，在本地对照源清单验证。发现缺失、大小或哈希不符，先处理传输，不继续上传错误包
- 临时来源记录有效期；凭据或签名直链只经适合的安全交接通道传递，不放公共仓库、不写公开收据
- 解压前检查目录结构和路径安全，禁止包内绝对路径、父目录穿越以及越界符号链接。压缩包本身和展开后的逐文件验证属于不同检查

## 幂等清单与中断恢复

每个文件保留稳定记录：项目标识、相对路径、内容 SHA-256、字节数、目标逻辑键、远端对象标识、上传状态、回读结果和索引状态。幂等判断依赖同一目标与同一内容，不依赖“文件名相同”。

状态依次为 pending → transferred → local_verified → uploaded → readback_verified → indexed → browser_checked；blocked 和 failed 不表示成功。允许只有项目级浏览器验收，文件记录应链接到对应收据，不编造每项都播放过。

恢复时：

1. 先读上次收据和当前目标状态，确认本轮授权仍适用
2. 已在相同目标回读验证的同一哈希文件，可以复用记录；远端状态不明时先核验，不重复盲传
3. 只有“上传返回成功”但未回读的项，补下载和哈希核验；损坏项仅修复对应对象
4. 已上传但未索引的项，补索引；索引已有但文件缺失或不匹配，修正前先确认实际状态
5. 内容变化则新建版本或按明确允许的更新策略处理；不把旧回读证据套在新字节上

## 上传 索引和浏览器验收

1. 再核对上传数据、目标和可见范围。素材库入口有密码不代表背后的对象直链私有；公开上传必须落在已授权范围内
2. 运行已有项目导入流程，逐项保存真实返回状态。批次成功不代表每项成功
3. 对全部约定交付文件做上传后完整下载回读，按源清单逐项核对字节数与 SHA-256。只做 HEAD、HTTP 200 或部分区间下载不算完整回读
4. 核对并更新索引的标题、版本、比例、文案、附件与文件对应关系。优先运行项目已有校验；需要部署或提交时遵守当前授权，不自动推导发布权限
5. 在真实入口检查详情文案、各附件、下载、手机布局、封面和非静音播放。记录浏览器、视口、播放范围和实际结果；短时抽验不能代替完整看听
6. 可访问性按实际网络检查范围报告。没有大陆网络证据时，不写“已验证大陆可访问”

## 交付收据与结束

使用 [入库收据](../templates/local-library-receipt.json)。至少给出：项目和本轮范围、执行器确实做过的步骤、逐文件哈希及状态、索引改动、浏览器检查、版本或提交、剩余阻断与下一步。私有运行标识和证据留在项目记录，不进入公共 Skill。

成功要求是全部约定文件与索引匹配、下载回读通过、约定浏览器验收完成；不能仅说“上传完成”。部分成功时明确列出已通过和未通过范围，并保存可恢复状态。

本地备份、下载文件或原 ZIP 的清理由用户明确指示决定，不自动清理。任务因环境关闭或权限不足中止时保留交接与收据，报告阻断，不宣称已经恢复。
